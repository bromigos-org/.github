# .github

The Bromigos organization's community-health repository on GitHub.

- **`profile/README.md`** is the public organization profile shown at
  <https://github.com/bromigos-org>. It covers the network, its active
  operations, and the phased roadmap.
- **Status:** active. Edit the profile here; it's published as soon as it
  lands on `main`, with no CI.

This repository is **public**. Keep it public-safe: no internal hostnames,
infrastructure details, private repository links or unreleased plans
beyond what the profile already announces. Org members can find the
private network-wide systems map in the `platform` repository at
`docs/SYSTEMS.md`.

Org-wide defaults GitHub would pick up from here (issue templates,
`CONTRIBUTING.md`, `SECURITY.md`, funding) aren't set up yet.
